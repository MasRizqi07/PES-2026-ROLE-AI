Prinsip Kerja Algoritma (Zero-Library ML):

Aplikasi ini dibangun murni tanpa pustaka machine learning pihak ketiga (tanpa Scikit-Learn, Numpy, Scipy). Karakteristik pengguna dipetakan ke dalam ruang vektor berdimensi 5:

  • Agresivitas: Nilai instingtif penyerangan dan risiko.
  • Kreativitas: Kemampuan membuka ruang dan visi distribusi.
  • Disiplin: Kepatuhan bertahan dan penjagaan zonal.
  • Kerjasama: Sinergi kolektif dan aliran passing.
  • Refleks: Tanggap darurat krisis dan reaksi motorik kilat.

Langkah Penggunaan:

  1. Geser nilai 5 parameter pada panel sebelah kiri (skala 1.0 - 5.0).
  2. Klik tombol Hitung Prediksi KNN (K=5).
  3. Sistem akan mengukur jarak geometris Euclidean ke 32 sampel data latih seimbang.
  4. Hasil klasifikasi, radar chart 5 sumbu, dan berkas laporan analitis akan ditampilkan seketika.
Standar Integritas Akademik: Model dilengkapi mekanisme deterministik Inverse Distance Weighting (IDW) untuk menyelesaikan voting seri (tie-break).
